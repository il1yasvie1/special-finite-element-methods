# special-finite-element-methods

This repository provides a simple [Firedrake](https://www.firedrakeproject.org/) implementation on the special methods in the paper ([Babuška et al. (1994)](#babuska1994).

## Reference
- <a id="babuska1994"></a> Babuška, I., Caloz, G., & Osborn, J. E. (1994). Special Finite Element Methods for a Class of Second Order Elliptic Problems with Rough Coefficients. *SIAM Journal on Numerical Analysis*, 31(4), 945-981. https://doi.org/10.1137/0731051
